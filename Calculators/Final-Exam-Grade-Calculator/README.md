# <p align="center">Final Exam Grade Calculator</p>

## Description :-

The Final Exam Grade Calculator answers the classic end-of-semester question: *"What do I actually need on the final to get an X?"* It takes your current grade, your target grade, and the final exam's weight, then calculates the exact score required — and tells you if the target is already secured or out of reach.

## Tech Stacks :-

- HTML
- CSS
- JavaScript (pure, no dependencies)

## Features :-

- Instant calculation on click, no page reload.
- Handles impossible targets gracefully: shows "+100%" or "already enough" states instead of errors.
- Shows the math check (weighted sum) to prove the result.
- Clear validation messages for missing or out-of-range inputs.
- Mobile-responsive card layout.

## How it works :-

> Required score = (target − current × (100 − weight)/100) ÷ (weight/100)
